# 2026-10-25 スクロール描画の改善

## 確認した問題と変更

- エディタの可視範囲が少し移動しただけでハイライトを無効化し、非同期再解析と無色の表示を繰り返していた。文書版・パス・言語が一致する近隣範囲のトークンを再利用し、最大256KiBの解析窓と字句状態チェックポイントを保持する。
- 行レイアウトで文字ごとに最大256バイトの文書読み出しと確保を行っていた。32KiBの読込窓で通常のASCIIを処理し、非ASCII・結合文字・絵文字の境界は既存YYの書記素処理を使う。CRLFと空行の逆スクロールも回帰確認した。
- ホイールイベントごとに描画して入力が滞留し得た。連続する同じ方向・座標・修飾キーのホイールを最大64イベントまでまとめ、移動量を保存する。次のクリック・キー・逆方向の入力は次の描画後に処理する。メニュー外の単なるマウス移動では描画しない。通常のワーカー反映待ちは30msから8msにした。
- Markdownの縦スクロールでは表示済みのスタイル付きテキストを借用し、画像の多色セルを含む文字列複製や書記素分解を削減した。横スクロール・狭い表示幅は従来の境界処理を維持する。単独markdownViewerも同じ入力集約を使う。
- 計画描画の親子マップ、コスト付きラベル、警告・並列記号、行数文字列をCanvas作成時に保持し、パンのたびの再計算を削減した。

## 測定

Windows x64、デバッグビルド、同じ日本語・絵文字・タブを含む5000行の文書。120列×40行の行レイアウトと3行スクロールを200回実行した。

| 状態 | 200回の合計 |
| --- | ---: |
| 変更前 | 1.4669501秒 |
| 変更後の初回 | 0.1232289秒 |
| 最終確認 | 0.1219123秒 |

今回の行レイアウト測定では約12倍、処理時間は約92%減少した。端末エミュレーターの描画・通信を含むフレームレート測定ではなく、この数値を画面全体の倍率として扱わない。

```sh
cargo test --locked --bin yyte scrolling_row_layout_benchmark -- --ignored --nocapture
```

## 回帰検証

入力の集約数上限と順番、逆方向、CRLF・空行・結合文字・絵文字・タブ・読込窓境界、近隣スクロールで色が消えずワーカーを再起動しないこと、異なる文書版・言語に古い色を適用しないこと、プレビューの色と表示幅、7DBの計画描画を確認した。

Windows x64はfmt・全ターゲットClippy・通常86試験と外部5DBの明示実行5試験が成功。Linux x64も最終コードのfmt・全ターゲットClippy・通常102試験（実端末14試験を含む）が成功。

[5DBの実DBから生成した計画画面](../user/database-plan-examples.md)を利用者向け資料に追加し、SVGをラスタライズして文字・罫線・選択色とプロパティの位置を確認した。

Linuxの初回試験で、CRLF空行の試験がOS既定の改行正規化に依存していることを確認した。文書の改行形式を明示的にCRLFへ設定し、同じバイト位置をWindowsとLinuxで検証して通過した。

- 文書スナップショットと幅で行レイアウトを識別し、最大256行を再利用する。編集・Undo・文書差し替え・幅変更で更新する。
- Markdownは幅・横位置別に端末セルを最大512行、65,536セル相当まで保持する。新しい組版結果で破棄する。
- オブジェクトツリーとER・計画プロパティの組版を再利用し、見える範囲だけ描く。
- DB結果の自動列幅は結果単位で保持し、長い値は表示分のみ変換する。コピー・エクスポート用の元データを変更しない。
- diffはペインの表示幅に応じた部分だけ読み出す。UTF-8の途中切断で偽の置換文字が出ないようにした。疎な変更、密な追加、日本語・絵文字、CRLF、大きい位置への移動を検証した。

再現手順は [描画測定](../developer/render-performance.md) を参照。

## 最終検証

Windowsの通常試験93件、Linuxの通常試験109件（実PTY試験14件を含む）が成功。両OSでfmtと全ターゲットClippy（警告をエラー扱い）が成功。配布処理のPython試験2件も成功した。手動ベンチマーク3件と外部DB実接続試験5件は通常実行では対象外。全画面ベンチマークは別途明示実行し成功した。外部DB接続の過去の検証結果は別レポートに分け、今回の描画検証の成功件数へ加算しない。ARM版と実際の端末エミュレーターでのFPSは今回未測定。

見出し枠の全幅表示、コード背景（空行・折り返し行を含む）、背景色の復帰、変更破棄の明示確認、他タブの内容保持、最後のタブを閉じた後の空文書、キャッシュと通常描画のセル一致、編集・Undo・幅変更時の再レイアウトを回帰試験で確認した。
