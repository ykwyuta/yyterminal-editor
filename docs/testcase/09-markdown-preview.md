# 09 Markdownプレビュー・単独ビューアー

`yyte` の全画面プレビュー（F5）、並列プレビュー、単独の `markdownViewer` は同じ描画エンジン（`src/preview.rs` ほか）を使う。描画内容のシナリオ（UC-09-04〜UC-09-09）は原則として3経路すべてで確認する。

## 試験データ

- `demo/markdown-preview.md`、`demo/preview-pixels.png`
- PNG/JPEG/WebP/GIF（アニメーション）/BMP/ICO、透過PNG、SVG、壊れた画像、8193×8193の画像、20MiB超の画像
- `data:image/png;base64,...` の画像、`%20` を含む相対パスの画像
- ローカルHTTPサーバー（期限付き）で配信する画像、リダイレクト4回、5秒超の応答遅延
- 7万行を超える文書、128MiBを少し超える文書、257件の画像参照を持つ文書
- 各Mermaid図（flowchart各方向・循環・subgraph・style、sequence、er、class、state、未対応図種、65ノード）
- 6段階の見出し、入れ子リスト、開始番号付きリスト、タスクリスト、表（配置・数値・日本語・`<br>`・インライン装飾）、各言語のコードフェンス
- 制御文字・ANSIエスケープを含む本文、HTML・`<script>`
