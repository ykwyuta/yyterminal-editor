# 04 CSV/TSV/任意区切り・固定長の表編集

## 試験データ

- `demo/data.csv`（引用符内改行・日本語・カンマ・二重引用符）
- CRLF・LF・末尾改行なしの各CSV、一部のフィールドだけ引用符付きのCSV
- 129レコード以上、1MiBを超えるCSV、4097列のCSV、1MiBを超える単一レコードのCSV
- `|`、`;;`、4バイト区切り（例: `<||>`）、`\t` で区切ったファイル
- `demo/records.dat` + `demo/record.cpy`（13バイト、COMP-3、未定義領域 `DE AD`／`BE EF`、区切りなし）
- IBM EBCDIC（IBM-930等）でエンコードしたPIC X / PIC 9 / COMP / COMP-3 を含む80バイトレコード、CRLF/LF/NL区切り版
- 区切りが壊れたファイル、レコード長の倍数でないファイル、不正なCOMP-3バイトを含むファイル
