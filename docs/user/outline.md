# アウトライン編集

yyeditorと同じ `yyoutline` version 1のJSONを読み書きします。`.yyoutline` は開くと自動的にアウトライン表示になります。`.json` や新規文書は `表示 > アウトライン編集` または `アウトライン > アウトライン編集`（英語では `View > Outline editor`／`Outline > Outline editor`）で切り替えます。[作例](../../demo/outline-notes.yyoutline)も利用できます。

| 操作 | キー／メニュー |
| --- | --- |
| 表示項目の選択 | ↑／↓、Home／End、PageUp／PageDown、マウス、ホイール |
| 同じ階層に項目追加 | Enter。選択した枝全体の後ろに追加 |
| 項目の文章を編集 | F2。入力欄はCtrl+Uで消去、Enterで確定、Escで取消。貼り付けも可能 |
| 枝の階層を下げる／上げる | Tab／Shift+Tab。子孫も一緒に移動 |
| 枝を上／下へ移動 | Alt+↑／Alt+↓ |
| 折りたたみ／展開 | Space、または左側の▾／▸をクリック |
| 選択した階層にズーム | →、または●／番号をクリック |
| 上の階層／全体に戻る | ←／Esc |
| ブックマーク切り替え | Ctrl+B |
| ブックマークへ移動 | `次のブックマーク`／`Outline bookmarks`。繰り返すと次へ移動 |
| 参照を追加／解除 | Ctrl+Rまたは`参照を追加`、`参照を解除`。画面の項目IDを入力 |
| 参照先／参照元へ移動 | `参照先へ移動`／`参照元へ移動`。候補の項目IDを指定。Enterで先頭候補へ移動 |
| 枝を削除 | Delete。件数を確認し、`yes`と入力して確定 |
| 点／番号表示 | `点・番号表示の切り替え`／`Outline style` |
| URLを開く | `項目のURLを開く`／`Outline open URL`。選択項目の最初のHTTP(S) URLを既定のブラウザーへ渡す。Linuxではxdg-openが必要 |
| Markdown出力 | `Markdownに出力`／`Outline export`。新しい出力先を指定。既存ファイルは上書きしない |
| JSON原文に戻る | `JSON原文に戻る`／`Outline source` |
| 保存・履歴 | Ctrl+S／Ctrl+Z／Ctrl+Y。通常編集と同じ文書と履歴 |

新しい項目には空の文章が入ります。F2で文章を編集してください。Ctrl+C／X／Vは選択項目の文章を内部クリップボードへコピー／切り取り／置き換えます。システムからの貼り付けはF2の入力欄で端末の貼り付け操作を使います。ズーム先の先頭項目でEnterを押した場合は、その項目の末尾の子として追加します。

広い本文領域ではブックマークと参照元の一覧を右に表示し、クリックで移動できます。狭い画面では下部に選択項目のID・参照・参照元を表示し、メニューから移動できます。保存したIDを保持するので、項目名や枝の位置を変えても参照は維持されます。削除した項目への参照は`[missing]`として残り、Undoで復元できます。参照は同じ文書内の項目へのリンクです。

文書全体はメタデータを含め1 MiBまでです。階層の深さの固定上限はありません。読み取り専用文書は参照・移動・Markdown出力が可能で、編集は拒否します。不正なJSON・重複ID・不正階層・未知のバージョンはエラーになり、原文を保ちます。通常テキストやMarkdownの自動変換は行いません。

保存するJSONは `format: "yyoutline"`、`version: 1`、表示順の`nodes`配列を持ちます。各項目の`id`、0始まりの`depth`、`text`、`bookmark`、`collapsed`、参照先ID配列`refs`と、任意の`listStyle`（`bullets`／`numbered`）はyyeditorと共通です。未知の追加フィールドも保持します。ズーム・選択位置はファイルに保存しません。

Markdown出力は全文書を対象とし、第1〜6階層を見出し、第7階層以降を入れ子リストにします。番号表示では番号付きリストにし、各親の下で番号を振り直します。項目内の改行は空白にし、Markdown記号は文字としてエスケープします。参照・ブックマーク・折りたたみ情報は含めません。UTF-8（BOMなし）、最大1 MiBで、新しいファイルに保存します。JSON原文は変更しません。
