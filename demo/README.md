# 表編集デモ

リポジトリ直下から `cargo run --release --locked -- demo` で起動します。以下のファイルは変更してよい検証用データです。

## CSV

1. エクスプローラーで `data.csv` を選択してEnter。
2. F7で表表示。引用符内の改行、日本語、カンマ、二重引用符を確認できます。
3. 矢印キーでセルを選択し、Enter。Ctrl+Aで入力内容を消して新しい値を入力し、Enterで確定します。セル内改行はAlt+Enterです。
4. Ctrl+Sで元のCSVへ保存。Ctrl+Z/ Ctrl+Yで変更をUndo/Redoできます。

## 固定長・パック十進数

1. `records.dat` を開き、F1メニューから `Fixed-length table` を選択。
2. `record.cpy;13;MS932;none` を入力します。コピーブックは現在のエクスプローラーフォルダーからの相対パスです。
3. 専用タブにID、金額、名前が表示されます。金額は先頭行が12345、次行が-12です。
4. 金額を42へ変更して保存すると、COMP-3の `00 04 2C` になります。

1レコード13バイト、コピーブックにある項目は11バイト、残り2バイトは未定義領域です。先頭行末の `DE AD` と次行末の `BE EF` は、他の項目を編集しても保持されます。レコード間の改行はありません。

桁あふれ、項目幅を超える文字列、表現できない文字、小数桁の欠落は拒否します。F9で新しいレコードを末尾へ追加、F8で選択中のレコードを削除します。これらもUndoできます。

元の内容へ戻す場合は、この `demo` フォルダーのファイルをGitから復元してください。


## ブック・寸法・固定長エクスポート・比較

- 表を開いた状態で `Spreadsheet mode` を選ぶと、別タブで数式やソート・フィルターを使えます。`Save as` で `.yys` を保存できます。
- Shift+矢印またはマウスのドラッグで範囲選択し、`Column width` と `Row height` で寸法を変更できます。ブックでは `.yys` に寸法も保存されます。
- 固定長の表またはブックで `Export fixed-length` を選び、新しい出力先を指定します。未編集の元バイトと固定長の位置関係が保持されます。ブックではソート・フィルターの表示順が出力対象です。
- `Compare file (yymerge)` で比較先を指定すると左右比較になります。N/Pで差分へ移動、F2で編集へ戻ります。数値や文字を変更したコピーと元データを比べられます。


## 画像とMermaid

`markdown-preview.md` を開いてF5を押すと、同じフォルダーのPNGがドット絵になり、フローチャート・シーケンス・ER・状態遷移がASCIIで表示されます。`cargo run --locked --bin markdownViewer -- demo/markdown-preview.md` で単独ビューアーでも試せます。`--plain` を付けると非対話のテキスト出力になります。
